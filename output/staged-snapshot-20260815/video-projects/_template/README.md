# New track video-project template

Copy this directory, rename it to a stable lowercase project ID, and replace every `new-track-project` value. Keep project-specific creative direction and shots here; do not add track names or stories to generic `backend/app/video_generation/` source.

Recommended creation flow:

1. Complete the existing TrackPrompt analysis.
2. Export/use its StoryPlan and ShotPlan.
3. Write one creative bible.
4. Choose 8–20 generated shots grouped into normalized chapters.
5. Start with Fast 1080p and one candidate per shot.
6. Set a cap larger than the base estimate but still explicitly bounded.
7. Compile and review provider request previews before authorizing.
