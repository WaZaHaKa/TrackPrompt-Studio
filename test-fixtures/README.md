# Synthetic test fixtures

This directory is reserved for audio generated by `tools/generate_test_audio.py`.
Generated files are intentionally ignored by Git; regenerate them on the machine
where tests or manual checks run.

From the repository root:

```bash
python tools/generate_test_audio.py
```

The generator creates deterministic click tracks at 120 BPM and accented 90 BPM,
an accented 3/4 rhythm, C-major and A-minor progressions, a known-range tone
sequence, mono and wide-stereo signals, clipped/quiet/silent signals, an
intro-A-B-A-outro arrangement, and invalid/truncated media. They are mathematical
test signals, not recordings of copyrighted music. Do not add downloaded songs,
commercial recordings, or personal recordings to this directory.

Backend tests should prefer temporary generated fixtures when persistence is not
needed. If the generator's output set changes, update its tests and the analysis
methods documentation together.
