# Release and deployment gates

| Gate | Who runs it | Evidence required | Current package status |
|---|---|---|---|
| Core/library correctness | Deterministic local test runner | Suite logs and exit codes | See VERIFICATION_REPORT.md |
| Existing Companion integration | DeepSeek builder + local runner | Baseline/current app tests, route/cache/UI checks | Not performed on your machine |
| Independent review | Kimi K3, read-only | Specific findings tied to diff/spec/evidence | Prompts/configurator supplied; not executed here |
| TrackPrompt root-cause fix | Local Codex + runner | Actual causal defect + failing/passing regression | Requires inaccessible current local runner |
| Windows process durability | Windows operator/agent | OS lock, parent/tool disconnect, supervised restart tests | Not tested on Windows here |
| Existing-run reconciliation | Local execution owner | Same run, verified raw binding, correlated Shot002, no duplicate POST | Not performed here |
| End-to-end monitoring | Windows host + WSL Companion | Actual SSH/API reconnect and history/freshness tests | Synthetic local API/client tests only |
| Final promo output | TrackPrompt + operator | 60sec/1080p24/1440frames, audio/visual verification | No movie generated by this kit |

Do not skip a gate because an LLM says “done”. No model prompt guarantees correctness.
Every agent reports passed, failed, skipped and not-run distinctly. Missing provider
history remains ambiguous unless independent evidence establishes the actual attempt.

No additional paid rendering, account purchases, new public listener, automatic VPN
trust, global process kill or broad cleanup is authorized by these packages.
